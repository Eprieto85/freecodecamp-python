## How this repo is organized

Each exercise lives in its own folder with a `main.py` file I typed and tested myself while solving it on the platform. Workshops and labs are grouped by module, in the same order as the curriculum.

```
01-fundamentals/
02-installing-python/
...
```

Folders are added as each module is completed.
